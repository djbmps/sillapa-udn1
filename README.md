## 2. ติดตั้ง (ครั้งเดียว ~20 นาที)

### 2.1 สร้างฐานข้อมูล
1. อัปโหลด `sillapa-udn1-database.xlsx` ขึ้น **Google Drive**
2. คลิกขวา → **เปิดด้วย → Google ชีต** แล้ว **ไฟล์ → บันทึกเป็น Google ชีต**
3. คัดลอก **SPREADSHEET_ID** จาก URL — ส่วนที่อยู่ระหว่าง `/d/` กับ `/edit`

### 2.2 ติดตั้ง API
4. ในชีตนั้น เลือก **ส่วนขยาย → Apps Script**
5. ลบโค้ดเดิม วางเนื้อหาจาก `Code.gs` ทั้งหมด
6. แก้ 2 บรรทัดบนสุด
   ```js
   const SHEET_ID = 'วาง SPREADSHEET_ID ที่คัดลอกมา';
   const SECRET   = 'ข้อความลับยาว ๆ ที่ตั้งเอง อย่าให้ใครรู้';
   ```
7. กด **Deploy → New deployment → เลือกชนิด Web app**
   - Description: `sillapa v1`
   - **Execute as: Me**
   - **Who has access: Anyone**
8. กด Deploy → อนุญาตสิทธิ์ → **คัดลอก Web app URL** (ลงท้ายด้วย `/exec`)

### 2.3 สร้างบัญชีผู้ใช้
9. กลับไปที่ชีต รีเฟรชหน้า จะเห็นเมนูใหม่ **“ศิลปหัตถกรรมนักเรียน”**
10. เลือก **ศิลปหัตถกรรมนักเรียน → สร้างบัญชีผู้ใช้ทั้งหมด**
    ระบบจะสร้างบัญชีให้อัตโนมัติในชีต `Users` — ผู้ดูแลเขต 1 บัญชี และโรงเรียนทุกแห่ง (ชื่อผู้ใช้ `sc0001` … ตามเลข SMIS 4 ตัวท้าย)
11. เปิดชีต `Users` เพื่อดูรหัสผ่านที่ระบบสุ่มให้ แล้วแจกให้โรงเรียน

### 2.4 เผยแพร่หน้าเว็บ
12. สร้าง repository ใหม่บน GitHub (ตั้งเป็น Public)
13. อัปโหลด `index.html` เข้าไป
    - ถ้าต้องการฝัง URL ของ API ถาวร ให้แก้บรรทัด `const API_URL_DEFAULT = '';` เป็น URL จากข้อ 8 ก่อนอัปโหลด
14. ไปที่ **Settings → Pages** → Source: `Deploy from a branch` → Branch: `main` / `root` → Save
15. รอ 1–2 นาที จะได้ลิงก์ `https://<ชื่อผู้ใช้>.github.io/<ชื่อ repo>/`
16. เปิดเว็บ → เมนู **ตั้งค่าเชื่อมฐานข้อมูล** → วาง Web app URL → บันทึก (ถ้าไม่ได้ฝังไว้ในข้อ 13)

> ยังไม่ได้ทำข้อ 2.1–2.3 ก็เปิดเว็บใช้งานได้ทันทีใน **โหมดตัวอย่าง** — ข้อมูลเก็บในเครื่องผู้ใช้เอง
> เข้าสู่ระบบด้วย `admin` / `admin` (ผู้ดูแลเขต) หรือ `admin-g01` / `admin` (ผู้ดูแลกลุ่มเมือง 1)

## 3. ระบบทำอะไรได้

### หน้าเว็บสาธารณะ กับ ระบบหลังบ้าน แยกกันชัดเจน
- **หน้าเว็บสาธารณะ** — ใครก็เปิดดูได้ ไม่ต้องล็อกอิน มีแบนเนอร์หัวเว็บ แถบเมนูด้านบน และท้ายเว็บ
  หน้าแรก · ข่าวประชาสัมพันธ์ · รายการแข่งขัน · ตารางแข่งขัน · ผลการแข่งขัน · ตารางเหรียญ · ทะเบียนโรงเรียน · เอกสารดาวน์โหลด
  เห็นได้เฉพาะ **ข้อมูลที่เปิดเผยได้** — ไม่มีเมนูตั้งค่า ไม่มีเมนูจัดการใด ๆ ปนอยู่
- **ระบบหลังบ้าน** — เข้าจากปุ่ม “เข้าสู่ระบบ” มุมขวาบน เป็นหน้าจอเมนูด้านข้างสำหรับผู้ดูแล
  มีปุ่ม “🌐 ไปหน้าเว็บสาธารณะ” กลับออกมาได้ตลอด
- **เมนูบริหารจัดการจะโผล่ก็ต่อเมื่อล็อกอินแล้วเท่านั้น** ทั้งระดับเขตและระดับกลุ่ม
  ถ้ายังไม่ล็อกอินแล้วพิมพ์ลิงก์หน้าหลังบ้านเข้ามาตรง ๆ ระบบจะเด้งไปหน้าเข้าสู่ระบบ
  และฝั่ง API ก็ตรวจสิทธิ์ซ้ำอีกชั้น เรียกข้ามไปตรง ๆ ก็ไม่ได้
- ออกจากระบบเมื่อไร เมนูหลังบ้านหายทันทีและกลับไปหน้าเว็บสาธารณะเอง
- แยกกันทั้งระดับเขตและระดับกลุ่ม — เลือกกลุ่มจากเมนูมุมขวาบน เว็บทั้งหน้าจะเปลี่ยนเป็นของกลุ่มนั้น พร้อมแบนเนอร์ของกลุ่มเอง

### เปิด-ปิดระบบ & สิทธิ์การพิมพ์
เมนูหลังบ้าน **“🔐 เปิด-ปิดระบบ & สิทธิ์การพิมพ์”** (เขต · กลุ่ม)
งานพิมพ์ทุกอย่างเป็นระบบ “ปิดไว้ก่อน เปิดเมื่อพร้อม” — คุมได้ 3 เรื่อง

| เรื่อง | ตั้งค่าที่ | ผลเมื่อยังปิด |
|---|---|---|
| เกียรติบัตร | หน้า “🎖️ ระบบเกียรติบัตร” | เมนู “เกียรติบัตร” **ไม่แสดงบนเว็บสาธารณะ** ดาวน์โหลดไม่ได้ |
| บัตรประจำตัว | หน้านี้ | ปุ่มพิมพ์บัตรจะเตือนว่ายังไม่เปิดระบบ |
| เอกสารการแข่งขัน | หน้านี้ | สร้าง/พิมพ์เอกสารไม่ได้ |

- ค่าที่เขตตั้งเป็น**ค่าเริ่มต้นของทั้งเขต** · กลุ่มโรงเรียนตั้งทับเฉพาะกลุ่มตัวเองได้
- ใส่ข้อความอธิบายได้ว่า “จะเปิดวันไหน” เพื่อให้โรงเรียนเห็นเหตุผล
- **ผู้ดูแลเขตทดลองพิมพ์ตรวจสอบได้ก่อนเปิดระบบ** เพื่อเช็กพื้นหลังและตำแหน่งข้อความ

### ปีการศึกษา · สำรองข้อมูล · ล้างผลการแข่งขัน
เมนูหลังบ้าน **“🗄️ ปีการศึกษา & สำรอง/ล้างข้อมูล”**
ระบบนี้ออกแบบให้ **ใช้ซ้ำได้ทุกปี** ไม่ต้องสร้างชีตใหม่และไม่ต้องกรอกโรงเรียน 214 แห่งใหม่

**① ข้อมูลงานและปีการศึกษา** (เฉพาะผู้ดูแลเขต)
- แก้ **ครั้งที่** · **ปีการศึกษา** · ชื่องาน · ชื่อเขตพื้นที่ · วันเปิด-ปิดรับสมัคร · เส้นตายส่งตัวแทน · รูปแบบเลขที่เกียรติบัตร
- ชื่องานตั้งให้อัตโนมัติจากครั้งที่ + ปีการศึกษา (พิมพ์ทับเองได้)
- บันทึกแล้วเปลี่ยนทันทีทั้งหน้าเว็บสาธารณะ เอกสารพิมพ์ และเกียรติบัตรทุกใบ

**② สำรองข้อมูล — ทำก่อนล้างเสมอ**
- **⬇️ สำรองทั้งหมด (.json)** — ยกทุกชีตออกมาเป็นไฟล์เดียว (ผู้ดูแลกลุ่มได้เฉพาะกลุ่มตน)
- **⬇️ ผลการแข่งขัน / ตารางเหรียญ / รายชื่อผู้สมัคร (.csv)** — เปิดใน Excel ได้เลย
- 🛟 วิธีที่ปลอดภัยที่สุดคือ **ทำสำเนาไฟล์ Google Sheet ทั้งไฟล์** (ไฟล์ → ทำสำเนา) เก็บไว้เป็นคลังของปีนั้น
  ไฟล์ `.json` ใช้เปิดดูย้อนหลัง แต่ยังไม่มีระบบนำกลับเข้าอัตโนมัติ

**③ ล้างข้อมูล 3 ระดับ**

| ระดับ | ลบอะไร | เก็บอะไร | ใครทำได้ |
|---|---|---|---|
| ① ล้างเฉพาะผลการแข่งขัน | คะแนนกรรมการ · ผลตัดสิน · เหรียญ · อันดับ · การโอนตัวแทน | ผู้สมัคร นักเรียน ครู ตารางแข่ง ทุกอย่าง | เขต · กลุ่ม (เฉพาะกลุ่มตน) |
| ② ล้างข้อมูลการแข่งขัน | ① + ผู้สมัคร นักเรียน ครูผู้ฝึกสอน ตารางแข่งขัน | โรงเรียน กลุ่ม รายการ เกณฑ์ สนาม กรรมการ ผู้ใช้ ข่าว | เขต · กลุ่ม (เฉพาะกลุ่มตน) |
| ③ เริ่มปีการศึกษาใหม่ | ② ทั้งเขตทุกกลุ่ม + ตั้งครั้งที่/ปีใหม่ + ปิดสิทธิ์การพิมพ์และเกียรติบัตรกลับเป็นค่าเริ่มต้น | ทะเบียนโรงเรียน 214 แห่ง · กลุ่ม 20 กลุ่ม · รายการและเกณฑ์ · บัญชีผู้ใช้ · เทมเพลตเกียรติบัตร/บัตร | **เฉพาะผู้ดูแลเขต** |

ระดับ ③ ติ๊กเลือกเพิ่มได้ว่าจะล้าง ข่าว/เอกสาร · ทำเนียบกรรมการและคณะกรรมการดำเนินงาน · สนามแข่งขัน · ประวัติการใช้งาน

**กันพลาด 4 ชั้น** — ติ๊กยืนยันว่าสำรองแล้ว → พิมพ์คำว่า `ล้างข้อมูล` ให้ตรง → กล่องยืนยันครั้งสุดท้ายบอกระดับและขอบเขต → ฝั่ง API ตรวจสิทธิ์และคำยืนยันซ้ำอีกครั้ง
ทุกครั้งที่ล้าง ระบบบันทึกลงชีต `AuditLog` ว่าใครล้าง ระดับไหน ขอบเขตไหน และลบไปกี่แถว

> **ลำดับที่แนะนำเมื่อขึ้นปีใหม่**
> 1. สำรอง `.json` + `.csv` และ **ทำสำเนาไฟล์ Google Sheet** ของปีเก่าเก็บไว้
> 2. อัปเดตทะเบียนโรงเรียนในชีต `Schools` (โรงเรียนยุบ/รวม/จำนวนนักเรียนใหม่)
> 3. อัปเดตรายการแข่งขันและเกณฑ์ตามประกาศ สพฐ. ของครั้งนั้น
> 4. เข้าหน้านี้ → เลือก **③ เริ่มปีการศึกษาใหม่** → ใส่ครั้งที่และปีใหม่ → ล้าง
> 5. ตั้งแบนเนอร์ ข่าว และวันเปิด-ปิดรับสมัครใหม่ แล้วค่อยเปิดสิทธิ์การพิมพ์เมื่อถึงเวลา

- จัดการเอกสารดาวน์โหลดแยกหมวด ระเบียบ / เกณฑ์ / หนังสือ / ใบสมัคร

### กลุ่มโรงเรียนจัดแข่งเอง (เหมือนที่เขตทำทุกอย่าง)
- เลือกกลุ่มจากมุมขวาบน เว็บจะเปลี่ยนเป็น **สนามคัดเลือกของกลุ่มนั้น** — เปลี่ยนชื่อ เปลี่ยนสี ขึ้นแถบ “← ไปเว็บระดับเขต” เพื่อไม่ให้ครูสับสนว่ากำลังอยู่เว็บไหน
- กลุ่มเห็นเฉพาะโรงเรียนสมาชิกของตัวเอง (เช่น กลุ่มเมือง 1 เห็น 10 โรงเรียน)
- รับสมัคร → จัดกรรมการ → ให้คะแนน → ประกาศผล → โอนตัวแทน ครบวงจรในกลุ่ม

### เพิ่ม / ลด / แก้ รายการแข่งขันและเกณฑ์ได้เอง
- เมนู **จัดการรายการ & เกณฑ์**
- เพิ่มรายการใหม่ แก้ระดับชั้น จำนวนคนต่อทีม เวลาแข่ง จำนวนกรรมการ โควตาส่งเข้าเขต ปิด/เปิดรายการ
- ตั้งเกณฑ์ให้คะแนนรายหัวข้อ — ระบบ **บังคับให้คะแนนเต็มรวมกันได้ 100 พอดี** ไม่งั้นบันทึกไม่ได้
- ลบรายการที่มีผู้สมัครแล้วไม่ได้ (ต้องเปลี่ยนสถานะเป็น “ปิด” แทน) กันข้อมูลหาย

### กรรมการกรอกคะแนนออนไลน์ — และมีใบกระดาษสำรอง
- เมนู **ให้คะแนน** เลือกรายการ + เลือกว่าเป็นกรรมการคนที่เท่าไร แล้วกรอกคะแนนรายหัวข้อ รวมให้อัตโนมัติ
- ระบบ **ปิดชื่อโรงเรียน** ระหว่างให้คะแนน (แสดงเป็น “หมายเลข 01”) ตั้งปิด/เปิดได้ที่ชีต `Config`
- เน็ตล่มหน้างาน → กด **🖨️ ใบให้คะแนนกระดาษ** พิมพ์ใบที่มีหัวข้อและคะแนนเต็มครบ ให้กรรมการเขียนมือ
- กรอกย้อนหลังได้ด้วยปุ่ม **บันทึกเป็นคะแนนจากกระดาษ** ระบบจะทำเครื่องหมายว่ามาจากกระดาษไว้ตรวจสอบได้

### ประกาศผลระดับกลุ่ม
- ระบบเฉลี่ยคะแนนจากกรรมการทุกคน ตัดเหรียญตามเกณฑ์ สพฐ. **80 / 70 / 60**
- **คะแนนเท่ากันได้เหรียญและอันดับเท่ากัน** (1, 2, 2, 4)
- เตือนเมื่อกรรมการให้คะแนนต่างกันเกิน 15 คะแนน ให้หารือก่อนประกาศ
- ประกาศแล้ว **ล็อกคะแนนทันที** และขึ้นจอผลสดกับหน้าเว็บสาธารณะ

### โอนข้อมูลเข้าระบบเขตพื้นที่
- เมนู **โอนตัวแทนเข้าเขต** ตั้งโควตาต่อกลุ่มและเกณฑ์ขั้นต่ำ (ส่งขึ้นทุกกรณี / ต้องได้ทองแดงขึ้นไป / ต้องได้ทองเท่านั้น)
- ระบบสร้างผู้สมัครระดับเขตให้อัตโนมัติ **ยกข้อมูลนักเรียนและครูผู้ฝึกสอนไปด้วย** พร้อมป้ายบอกกลุ่มต้นทางและอันดับ
- **คะแนนเท่ากันที่เส้นโควตา → ส่งขึ้นทั้งคู่** ตามกฎ “เท่ากันได้เท่ากัน”
- ตัวแทนสละสิทธิ์ → ระบบเสนออันดับถัดไปของกลุ่มเดียวกันให้เลื่อนแทน พร้อมบันทึกร่องรอย

### ระบบเกียรติบัตร — เปิด/ปิดได้ ออกจากผลการแข่งขันจริง
**หน้าสาธารณะ** เมนู “เกียรติบัตร” — ไม่ต้องล็อกอิน เลือกประเภท → เลือกโรงเรียน → ค้นชื่อ → กด “ออกเกียรติบัตร” → `Ctrl/⌘ + P` พิมพ์หรือบันทึก PDF (A4 แนวนอน)

**หลังบ้าน** เมนู **“🎖️ ระบบเกียรติบัตร”**
- **สวิตช์เปิด/ปิดการดาวน์โหลด** — ปิดอยู่จะขึ้นข้อความที่ตั้งไว้แทน เช่น “เกียรติบัตรจะเปิดให้ดาวน์โหลดวันที่ …”
  เขตคุมของเขต · แต่ละกลุ่มเปิด/ปิดของกลุ่มเองแยกได้
- **อัปโหลดพื้นหลังได้จากเครื่องโดยตรง** 4 แบบแยกกัน — นักเรียน · ครูผู้ฝึกสอน · คณะกรรมการตัดสิน · คณะกรรมการดำเนินงาน
  คลิกเลือกไฟล์หรือลากรูปมาวาง ระบบย่อขนาดและอัปโหลดขึ้น Google Drive ของเขตให้เอง แล้วตั้งสิทธิ์ให้เปิดดูได้อัตโนมัติ (ไม่ต้องหาลิงก์เอง)
- แก้ข้อความทุกบรรทัดและ**เลื่อนตำแหน่งแนวตั้งเป็น %** ให้ตรงกับกรอบในรูปพื้นหลัง เห็นตัวอย่างสดขณะพิมพ์
- ตัวแปรที่ใช้ได้: `{ชื่อผู้รับ} {โรงเรียน} {รายการแข่งขัน} {ระดับชั้น} {ผล} {คะแนน} {อันดับ} {หน่วยงาน} {หน้าที่} {วันที่} {เลขที่}`
- **เลขที่เกียรติบัตรรันอัตโนมัติ** ตามรูปแบบในชีต `Config` (`cert_number_format`)
- ตั้งได้ว่าจะออกให้ทุกคนที่เข้าแข่ง หรือเฉพาะผู้ที่ได้เหรียญทองแดง/เงิน/ทองขึ้นไป
- ปุ่ม “นับใหม่” บอกจำนวนเกียรติบัตรที่ออกได้ตอนนี้ แยกตามประเภท
- ตาราง **คณะกรรมการดำเนินงาน** เพิ่ม/แก้/ลบรายชื่อ พร้อมหน้าที่ที่จะพิมพ์ลงเกียรติบัตร และเปิด/ปิดรายคน

**ข้อมูลมาจากไหน** — นักเรียนและครูผู้ฝึกสอนดึงจากผู้สมัคร + ผลที่ **ประกาศแล้ว** เท่านั้น · กรรมการตัดสินดึงจากการมอบหมายกรรมการเข้ารายการ · คณะกรรมการดำเนินงานดึงจากชีต `Staff`

### บัตรประจำตัว A6 — อัปโหลดรูปถ่ายและพื้นหลังได้
เมนูหลังบ้าน **“🪪 บัตรประจำตัว”** (เขต · กลุ่ม · โรงเรียนใช้ได้)
- **4 ประเภท** — นักเรียน · ครูผู้ฝึกสอน · คณะกรรมการตัดสิน · คณะกรรมการดำเนินงาน
- **อัปโหลดพื้นหลังบัตร** แยกตามประเภท (A6 แนวตั้ง 105×148 มม. · แนะนำรูป 1240×1748 px) พร้อมตัวอย่างสด
- **อัปโหลดรูปถ่ายรายคน** อยู่ในกล่อง **“② รายชื่อ และ 📷 อัปโหลดรูปถ่ายรายคน”** ท้ายหน้า
  ปุ่ม **“📷 อัปโหลดรูป”** อยู่ท้ายแถวของแต่ละคน — กดแล้วเลือกรูปจากเครื่อง ระบบย่อและเก็บให้อัตโนมัติ
  บรรทัดสรุปบอกตลอดว่ามีรูปแล้วกี่คน ยังขาดกี่คน
  ⚠️ ถ้าตารางยังว่างจะยังไม่มีปุ่มนี้ — ระบบจะบอกว่าต้องไปเพิ่มรายชื่อที่ไหนก่อน พร้อมปุ่มลัดพาไป
  (นักเรียน/ครูผู้ฝึกสอน → หน้าผู้สมัครแข่งขัน · กรรมการตัดสิน → ทำเนียบกรรมการตัดสิน · กรรมการดำเนินงาน → ระบบเกียรติบัตร)
- เลื่อนตำแหน่งรูปถ่าย ชื่อ รายละเอียด หน่วยงาน เป็น % ให้ตรงกับกรอบในพื้นหลัง
- ติ๊กเลือกรายชื่อ → **พิมพ์บัตรที่เลือก** ระบบจัด **4 ใบต่อกระดาษ A4 หนึ่งแผ่น** พร้อมเส้นประสำหรับตัด
  (พิมพ์ได้เมื่อเปิดสิทธิ์ที่หน้า “🔐 เปิด-ปิดระบบ & สิทธิ์การพิมพ์” แล้ว)
- รายชื่อดึงจาก**ผู้สมัครที่ยืนยันแล้ว** (ไม่ต้องรอประกาศผล เพราะบัตรต้องใช้ก่อนวันแข่ง)

### พิมพ์เอกสารการแข่งขัน
เมนู **พิมพ์เอกสาร** → เลือกรายการ → เลือกเอกสาร → กด `Ctrl/⌘ + P` เพื่อพิมพ์หรือบันทึกเป็น PDF
> ต้องเปิดสิทธิ์ที่หน้า **“🔐 เปิด-ปิดระบบ & สิทธิ์การพิมพ์”** ก่อน ไม่งั้นจะพิมพ์ไม่ได้ (ผู้ดูแลเขตทดลองพิมพ์ได้)
- ใบรายชื่อผู้เข้าแข่งขัน
- **ใบให้คะแนนกระดาษ (รายกรรมการ)** — มีหัวข้อและคะแนนเต็มตามเกณฑ์จริง
- ใบสรุปคะแนนรวมของรายการ
- ใบประกาศผลการแข่งขัน
- ใบเซ็นชื่อคณะกรรมการ / ใบเซ็นชื่อผู้เข้าแข่งขัน
- ตารางการแข่งขันรายสนาม

### จอฉายหน้างาน
- **จอผลสด** ตารางเหรียญวิ่งสด และ **จอคิว NOW/NEXT** รายสนาม — เปิดเต็มจอ ไม่ต้องล็อกอิน กด `Esc` ออก

### กติกาที่ระบบบังคับให้เอง
- รายการที่ระดับชั้นขึ้นต้นด้วย **ม.** (78 รายการ) สมัครได้เฉพาะ **โรงเรียนขยายโอกาส 59 แห่ง** เท่านั้น
- โรงเรียนที่ไม่มีนักเรียน (เรียนรวมทุกชั้น 2 แห่ง) สมัครไม่ได้
- โรงเรียนหนึ่งลงรายการหนึ่งได้ทีมเดียว
- จำนวนนักเรียนในทีมต้องอยู่ในช่วงที่รายการกำหนด
- ทุกการแก้ไขสำคัญบันทึกลงชีต `AuditLog`

## 5. ข้อจำกัดที่ต้องรู้ก่อนใช้จริง

1. **Google Sheets ไม่ใช่ฐานข้อมูลจริง** — เร็วพอสำหรับระดับกลุ่ม (หลักพันแถว) แต่ถ้ารวมทั้งเขตไว้ไฟล์เดียวจะเริ่มหน่วง · **แยกไฟล์ชีตต่อกลุ่ม** คือข้อแนะนำที่สำคัญที่สุด — ดูตัวเลขและเหตุผลในข้อ 6
2. **โควตา Apps Script** — รันได้ไม่เกินราว 6 นาทีต่อครั้ง และมีโควตาเวลารวมต่อวัน (บัญชี Google Workspace ของเขตได้สูงกว่าบัญชี Gmail ฟรีมาก) · อย่าตั้งจอผลสดรีเฟรชถี่กว่า 15 วินาที
3. **สำรองข้อมูลก่อนวันแข่ง** — ที่ Google Sheets ให้ **ไฟล์ → ทำสำเนา** ทุกเย็นช่วงสัปดาห์แข่ง
4. **ห้ามเปลี่ยนชื่อชีตและชื่อคอลัมน์** เพราะสคริปต์อ้างอิงตามชื่อ (เพิ่มคอลัมน์ท้ายตารางได้)
5. **รายการแข่งขัน 188 รายการเป็นของ ครั้งที่ 73** — เมื่อ สพฐ. ประกาศรายการ ครั้งที่ 74 ให้เทียบและปรับในชีต `Activities` (เพิ่ม/ลด/แก้ได้ทั้งในเว็บและในชีต)
6. **เกณฑ์การให้คะแนน 745 หัวข้อเป็นค่าตั้งต้นตามกลุ่มสาระ** (4 หัวข้อ/รายการ รวม 100 คะแนน) ต้องแทนด้วยเกณฑ์จริงของแต่ละรายการตามคู่มือเกณฑ์
7. **เวลาที่ใช้แข่งต่อทีม (`duration_min`) เว้นว่างไว้** เพราะแหล่งข้อมูลไม่ได้ระบุ — ต้องกรอกเองก่อนใช้ตัวช่วยจัดตาราง ส่วน `judges_required` ตั้งค่าเริ่มต้นไว้ 3 คนทุกรายการ ให้ปรับตามจริง
8. **ข้อมูล ม.ปลาย ของโรงเรียนบ้านหมากแข้ง** ในไฟล์ต้นทางมีนักเรียน ม.ปลาย 475 คน แต่ช่อง “เปิดสอน” ระบุแค่ถึง ม.ต้น — ควรตรวจสอบกับข้อมูล DMC ล่าสุดอีกครั้ง
9. **PDPA** — ระบบเก็บเลขบัตรประชาชนแค่ 4 ตัวท้าย และไม่แสดงในหน้าสาธารณะ ห้ามเพิ่มคอลัมน์เลขบัตรเต็มลงในชีต

| **Scores** | **~2,400** | **~48,000** | **~45,000** |
| Results | ~200 | ~4,000 | ~3,800 |
| **รวมทั้งไฟล์** | **~3,400 แถว** | **~68,000 แถว** | **~64,000 แถว** |

Google Sheets รับได้ **10 ล้านเซลล์ต่อไฟล์** — ชีต Scores 48,000 แถว × 8 คอลัมน์ = 384,000 เซลล์ ยังห่างเพดานมาก
**เพดานไม่ใช่ปัญหา ความเร็วในการอ่านต่างหากที่เป็นปัญหา**

### เวลาที่ใช้ต่อการกดหนึ่งครั้ง (ประมาณการ)

| การทำงาน | ไฟล์ระดับกลุ่ม (~3,400 แถว) | ไฟล์รวมทั้งเขต (~68,000 แถว) |
|---|---|---|
| เปิดหน้าเว็บ (bootstrap) | < 1 วิ (มี cache 30 วิ) | 1–2 วิ |
| กรรมการบันทึกคะแนน 1 รายการ | ~1 วิ | 3–5 วิ |
| รวมคะแนน + ประกาศผล | 1–2 วิ | 5–8 วิ |
| โอนตัวแทนเข้าเขต | 1–2 วิ | 5–10 วิ |

### สิ่งที่แก้ไปแล้วในโค้ด (v1.1)

ปัญหาใหญ่กว่าขนาดข้อมูลคือ **วิธีเขียนโค้ด** — เวอร์ชันแรกเขียนลงชีตทีละแถว และอ่านทั้งชีตใหม่ทุกครั้งที่เขียน ทำให้ช้าแบบทวีคูณ (เพิ่ม n แถว = อ่าน n² แถว) แก้แล้วดังนี้

| จุด | เดิม | ใหม่ |
|---|---|---|
| เพิ่มข้อมูลหลายแถว | เขียนทีละแถว + อ่านทั้งชีตทุกแถว | `appendRows()` เขียนบล็อกเดียว |
| ออกรหัสใหม่ (`E00001`) | อ่านทั้งชีตทุกครั้ง | `nextIds()` อ่านคอลัมน์เดียวครั้งเดียว ออกได้ทีละหลายรหัส |
| อ่านหัวตาราง | อ่านทั้งชีต | อ่านแถวเดียว แล้วจำไว้ |
| บันทึกคะแนน | อ่านชีต Scores ใหม่ทุกช่องคะแนน | อ่านครั้งเดียว แยกเป็น “แก้” กับ “เพิ่ม” แล้วเขียนรวดเดียว |
| รวมคะแนน | ไล่ filter ทั้งชีตซ้ำทุกทีม | อ่านครั้งเดียว สรุปเป็น map |
| ลบหลายแถว | ลบทีละแถว อ่านใหม่ทุกครั้ง | `deleteRowsWhere()` ลบจากล่างขึ้นบนในรอบเดียว |
| สร้างบัญชี 234 บัญชี | เขียนทีละบัญชี (ช้ามาก อาจ timeout) | เขียนครั้งเดียวจบ |

ผลคือ **บันทึกคะแนนทั้งรายการ (9 ทีม × 4 หัวข้อ = 36 ช่อง) จากเดิมที่ต้องอ่านชีต 36 รอบ เหลืออ่านรอบเดียว**

### คำแนะนำที่สำคัญที่สุด — แยกไฟล์ชีตต่อกลุ่ม

```
sillapa-udn1-เขต        ← ไฟล์กลาง : Config, Groups, Schools, Activities, Criteria
sillapa-udn1-g01        ← กลุ่มเมือง 1
sillapa-udn1-g02        ← กลุ่มเมือง 2
...                        (20 ไฟล์)
```

ทำได้โดย **ทำสำเนาไฟล์ชีต 1 ชุดต่อกลุ่ม** แล้วในไฟล์ของกลุ่มนั้น ตั้ง `SHEET_ID` ใน Apps Script ให้ชี้ไฟล์ตัวเอง
ข้อดี:

- แต่ละไฟล์ค้างอยู่ที่ ~3,400 แถว เร็วตลอดงาน
- กลุ่มหนึ่งพังหรือแก้ผิด ไม่กระทบอีก 19 กลุ่ม
- โควตา Apps Script แยกกันคนละไฟล์ ไม่แย่งกันวันแข่ง
- ตอนโอนตัวแทนเข้าเขต ระบบส่งเฉพาะทีมที่ชนะ (ไม่กี่ร้อยแถว) ไปไฟล์กลาง ไม่ได้ยกทั้งกอง

### ขีดจำกัดของ Google ที่ต้องรู้

- **10 ล้านเซลล์ต่อไฟล์ชีต** — ไม่ใช่ข้อจำกัดในทางปฏิบัติสำหรับงานนี้
- **Apps Script รันได้ไม่เกิน ~6 นาทีต่อการเรียกหนึ่งครั้ง** — งานใหญ่ต้องแบ่งทำ (โค้ดที่แก้แล้วไม่มีงานไหนใกล้เคียง)
- **มีโควตาเวลารันรวมต่อวัน** และต่างกันระหว่างบัญชี Gmail ฟรีกับ Google Workspace — ถ้าใช้บัญชีของเขต (Workspace) จะได้โควตาสูงกว่ามาก ควรตรวจหน้าโควตาของ Google อีกครั้งก่อนวันแข่ง
- **จอผลสด** ตั้งรีเฟรชไว้ 15 วินาที — ถ้ามีจอฉาย 5 จอ = 20 คำขอ/นาที ยังสบาย แต่อย่าตั้งต่ำกว่านี้

### ถ้าโตเกินกว่านี้จริง ๆ

ถ้าวันหนึ่งเขตอยากรวมทุกกลุ่มไว้ที่เดียวและมีคนใช้พร้อมกันหลายร้อยคน ให้ย้ายฐานข้อมูลไปเป็น **Postgres ฟรีของ Supabase หรือ Neon** โดยไม่ต้องแก้หน้าเว็บ — เพราะหน้าเว็บคุยผ่าน `api(action, params)` ที่เดียว เปลี่ยนแค่ปลายทางของฟังก์ชันนั้น โครงตารางในชีตออกแบบให้ย้ายเป็นตารางฐานข้อมูลได้ตรง ๆ อยู่แล้ว

## 7. ลำดับงานที่แนะนำ

| ช่วง | ทำอะไร |
|---|---|
| ก่อนเปิดรับสมัคร | แทนรายการแข่งขันและเกณฑ์ด้วยของจริง · ตั้งโควตาต่อกลุ่ม · แจกบัญชีให้กลุ่มและโรงเรียน |
| เปิดรับสมัคร | โรงเรียนสมัครออนไลน์ · กลุ่มตรวจสอบและยืนยัน |
