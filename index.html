ขอเปลี่ยนตัวนักเรียน / ครูผู้ฝึกสอน

ยื่นคำขอออนไลน์ แนบหลักฐาน ลงลายมือชื่อในระบบ — ไม่ต้องส่งเอกสารกระดาษ

ขั้นตอนการขอเปลี่ยนตัว

  1. โรงเรียนยื่นคำขอ เข้าสู่ระบบด้วยบัญชีโรงเรียน เลือกรายการแข่งขันและทีมที่ต้องการเปลี่ยนตัว
  2. แนบหลักฐาน ถ่ายรูปจากมือถือหรือแนบไฟล์ เช่น ใบรับรองแพทย์ หนังสือย้าย หรือหนังสือของโรงเรียน
  3. ผู้อำนวยการโรงเรียนลงลายมือชื่อ เซ็นบนหน้าจอได้เลย ระบบบันทึกชื่อ ตำแหน่ง วันเวลา และเลขที่คำขอกำกับไว้
  4. ประธานกลุ่มโรงเรียน / เขตพื้นที่พิจารณา เมื่ออนุมัติ ระบบจะเปลี่ยนรายชื่อในทีมให้อัตโนมัติ และออกใบอนุญาตเปลี่ยนตัวอิเล็กทรอนิกส์พร้อมรหัสตรวจสอบ

สถานะระบบ

ขั้นตอนติดตั้ง (ย่อ)

  1. อัปโหลดไฟล์ sillapa-udn1-database.xlsx ขึ้น Google Drive แล้วเปิดด้วย Google Sheets
  2. ในชีตนั้นเลือก ส่วนขยาย → Apps Script วางโค้ดจาก Code.gs แล้วแก้ SHEET_ID และ SECRET
  3. กด Deploy → New deployment → Web app · Execute as: Me · Who has access: Anyone แล้วคัดลอก URL
  4. กลับมาที่หน้านี้ วาง URL ในช่องด้านบน แล้วกดบันทึก
  5. ในชีต เลือกเมนู ศิลปหัตถกรรม 74 → สร้างบัญชีผู้ใช้ทั้งหมด เพื่อออกบัญชีให้เขต/กลุ่ม/โรงเรียน
  6. อัปโหลดไฟล์ index.html ขึ้น GitHub repo แล้วเปิด Settings → Pages เผยแพร่จาก branch main
